Scaling i Mode shape values are relative within ±1: the point that moves most is 1, the others are proportional to it. The actual displacement (mm) is not part of a mode shape; it depends on the traffic and wind at that moment.

Scaling sets how many metres a value of 1 is drawn on screen. For example, at 1.2 m a sensor with z = −0.5 is drawn 0.6 m below its rest position. It is a visualization scale, not a real displacement; the same scale is applied to y and z.

Data and assumptions
  • Mode shape values: xlsx files obtained from the modal analysis of the classified data (Baseline 1–2, Test 1–3, y and z, Mode 1–8). The values are normalized to ±1 and relative; the actual amplitude and the y/z ratio are not included, so scaling is visual and the same for y and z.
  • Sensor positions and all lengths are taken from the 'position' attributes of A01–A30 in Rt345Bridge.h5, since the mode shape files contain no positions.
  • Row i of each xlsx file is read as sensor Ai. Modes with the same number in the y and z files are taken as the same mode. The sign (+/−) of a mode shape is arbitrary.
  • Only the area covered by the sensors is drawn; supports, span and cross-sections are not shown.
